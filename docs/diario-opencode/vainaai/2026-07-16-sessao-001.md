### 4. Correção do botão de idioma

O botão de alternância de idioma mostrava o **próximo** idioma (para qual ia mudar) em vez do **atual**. Isso causava confusão: o botão mostrava "🇧🇷 PT-BR" quando o site já estava em espanhol.

**Correção:** Variáveis renomeadas de `nextLocale*` para `currentLocale*` com lógica invertida:
- `currentLocaleFlag`: 🇧🇷 (pt-BR), 🇵🇹 (pt-PT), 🇪🇸 (es)
- `currentLocaleLabel`: PT-BR, PT-PT, ES
- `currentLocaleTitle`: nome completo do idioma atual
- `aria-label` atualizado para indicar idioma atual
